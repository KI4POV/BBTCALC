This is a simple calculator to for broadband ferrite transformers used at HF. This is geared toward QRP/Homebrew RF construction.

Operation is simple and self-explanatory. Enter the input and output impedance in ohms. It doesn't matter if you are going from low to high, or high to low. Then enter the frequency of operation in kHz. If using over a wide spectrum, enter the highest intended frequency.

The next page will have you choose the core you plan to wind the transformer on. AL values have been entered for cores commonly used in QRP construction. If your desired core is not listed, enter "0" to input a custom AL value. 

The output displays possible turns ratios, with multiples from 1-20. Ratios in green indicate that the inductive reactance of the smaller winding is at least 4 times lower impedance being matched.

This was written in QBX (QBasic compatible) using DOSBOX. The code should run under any of the QBasic variants. The binary is DOS-compatible. You will need a color display to see the results differentiated based on inductive reactance.
